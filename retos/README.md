# Banco de preguntas y respuestas del equipo

No hay retos reales registrados aún. No inventar flags, respuestas ni resultados. Microsoft y Dynatrace tienen carpetas separadas; dentro de cada reto, una carpeta por pregunta.

```text
retos/
  microsoft/<reto-id>/preguntas/<pregunta-id>/
    README.md
    analisis.md
    evidencias/
    intentos/<evento-id>.json
  dynatrace/<reto-id>/preguntas/<pregunta-id>/...
```

Copiar [plantillas](plantillas/README.md) al recibir una pregunta. El historial se conserva aunque todos los intentos sean incorrectos. [Protocolo de envíos](../docs/protocolo-respuestas.md).
