# Guía de estudio orientada a preguntas CTF

La preparación cubre los servicios y conceptos identificados en los workshops/PDF, no todo el catálogo Microsoft ni una predicción de flags. El temario exacto se ampliará con información del evento. No se han ejecutado estas prácticas en el entorno competitivo, todavía no entregado.

1. [Microsoft](microsoft.md): conceptos, navegación, backend/frontend, scripts, DevOps y diagnóstico.
2. [Dynatrace](dynatrace.md): cuenta/formación, métricas/logs/trazas, servicios, infraestructura, DQL y experiencia.
3. [Scripts y consultas](scripts-consultas.md): ejemplos adaptables con sus límites.
4. [Ejercicios de laboratorio](ejercicios.md): practicar búsqueda y revisión sin gastar intentos del CTF.

Estudiar un tema → localizarlo en laboratorio → explicar evidencia a la pareja → resolver ejercicio → registrar dificultad. El objetivo es poder obtener un dato correcto del entorno, no memorizar menús ni instalar todas las alternativas. Las rutas de UI pueden cambiar; identificar la capacidad y validar el entorno antes de concluir.
