# Índice de evidencias

Cada evidencia debe apoyar un requisito o una conclusión concreta. Usar rutas relativas dentro del repositorio. Comprobar qué datos se pueden compartir antes de incorporarlos a documentos o grabaciones.

| ID | Tarea o requisito | Archivo o enlace | Entorno y versión | Fecha o intervalo consultado | Pasos de comprobación | Resultado e interpretación | Verificador |
|---|---|---|---|---|---|---|---|

## Consultas de observabilidad

Para cada consulta registrar lenguaje (KQL o DQL), texto, filtros, intervalo temporal, entorno, resultado e interpretación. Registrar ausencia de datos como tal: no equivale automáticamente a ausencia de errores.

## Capturas y grabaciones

Nombrar los archivos por tarea y contenido. Conservar contexto suficiente para entender la comprobación. No incluir tokens, credenciales ni datos restringidos.
